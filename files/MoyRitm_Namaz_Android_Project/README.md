# МОЙ РИТМ · Намазы
Android-виджет с пятью намазами в тёмном стиле. Город: Астрахань. Данные: AlAdhan API, метод 3 (Muslim World League), school=0 (шафиитский Аср). Это расчётные значения, которые могут отличаться от местного расписания.

## Бесплатная сборка APK через GitHub
1. Создай **пустой публичный репозиторий** на github.com.
2. Загрузи **содержимое** этого архива в корень репозитория (включая скрытую папку `.github`).
3. Открой **Actions → Build Android APK → Run workflow** (или дождись сборки после push).
4. В завершённой сборке скачай **Artifacts → moy-ritm-namaz-apk**.
5. Распакуй ZIP, установи `app-debug.apk` на Android.
6. Зажми пустое место рабочего стола → **Виджеты** → **МОЙ РИТМ · Намазы**.

Для получения времени намазов требуется интернет; последнее расписание кешируется. Android обновляет виджет приблизительно раз в 30 минут (система может задерживать обновление). При смене даты новые данные загрузятся при следующем обновлении. Для корректной работы проверь доступ к интернету и разрешения энергосбережения.

Не публикуй debug APK как официальный релиз. Перед публичным распространением потребуется release-сборка и подпись.
